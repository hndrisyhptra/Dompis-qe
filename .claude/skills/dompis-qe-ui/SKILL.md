# Dompis QE UI Skill


Gunakan skill ini ketika membuat atau memperbaiki tampilan UI.


## UI Principles


Selalu buat UI dengan prinsip:


Enterprise Application

bukan:

Landing page

bukan:

AI dashboard


Prioritas:

1. Clarity
2. Usability
3. Consistency


---

## Before UI Coding


Sebelum coding:


Berikan:


- tujuan halaman
- user yang memakai
- komponen yang diperlukan
- responsive behavior


---

## Implementation


Gunakan:

- Tailwind CSS
- reusable component
- clean blade structure


Jangan membuat:

- inline style berlebihan
- komponen duplikat
- desain tidak konsisten


---

## Visual Direction


Dompis QE:

Professional
Corporate
Modern


Avoid:

- excessive animation
- futuristic style
- AI template style
